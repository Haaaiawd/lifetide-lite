# 对话式 AI 设计

## Field identity and boundary

本领域负责 Agent 的对话行为：提问策略、轮次节奏、上下文使用、暂定洞察的语言形式、依据说明、纠正吸收、范围拒绝和会话一致性。它不拥有产品路线、人格理论、人生设计方法、数据治理或危机政策；但必须把这些约束准确地表现在每一轮对话中。

## Project decisions this field changes

- 双 Agent 如何分工：Interviewer 围绕唯一最高影响未知生成下一波问题，Sensemaker 从整波回答中形成可追溯的工作记忆与一条暂定洞察。
- 什么时候追问具体经历、什么时候总结、什么时候承认信息不足或停止。
- 上传的简历/MBTI 如何进入上下文，以及如何防止材料文本或模型先验压过用户本人。
- 即时洞察怎样表达为可纠正假设，而不是权威判词或伪人格评分。
- 用户纠正、矛盾和“不知道”如何改变后续问题与回复。

## Project-specific diagnosis

人生试运行的对话优势应来自“记得你刚才说过什么，并能提出贴近情境的下一问”，而不是拟人化亲密或宏大分析。短体验要求 Agent 很快产生价值，但证据稀疏；最危险的输出是流畅、具体、听起来像真相的性格结论。

因此即时洞察必须保持三层结构：观察到的线索、当前可能解释、还需要验证的未知。简历和 MBTI 是用户可选上传的线索，不是真相：简历偏向公开成就，MBTI 是一次自陈框架，两者都不能直接生成稳定特质。对话应优先追问具体事件和反例，并允许用户直接改写系统理解。

## Principles, evidence, and sources

- `README.md` 要求区分事实、推断、冲突和未知，并以具体经历优先于简历、MBTI 与自我评价。
- `11_Life_Planning_and_Chat_Design.md` 提供画像只读、引用来源、漂移时重新访谈和有边界聊天的原始原则；Lite 将其前移到每个短波次。
- `14_AI_Engineering_and_Safety_Design.md` 提供结构化输出、Prompt 版本化、用户数据与系统指令隔离、模型回退和调用审计。
- 当前设计方向为双 Agent，而不是为显得智能而堆叠多 Agent；职责必须可测试。

## Distinctive stance and rejected defaults

- 提问先从用户选择的当前问题和具体情境开始，逐步追问行为、感受、取舍与反例；拒绝固定人格问卷伪装成对话。
- 每波恰好给一条即时洞察，在同一张纸条内分开“我目前的理解”“因为你提到”“还不确定”，并明确邀请用户校准；不以多条结论制造分析量感。
- 洞察必须可指向本轮回答或用户材料片段，并显式保留未知；拒绝无来源的“你本质上”。
- 不生成 MBTI 推断、人格百分比、潜力值、置信度伪小数或路线匹配分；结构化置信状态仅供流程控制，不包装成科学测量。
- 用户说“不像我”时先接受并询问最小必要澄清，更新工作记忆且避免再次复述旧判断；拒绝争辩和“模型只是建议”的敷衍。
- 不以“我一直陪着你”“只有我懂你”等关系性话术促成依赖。

## Consequences for design, implementation, and verification

- Interviewer 输入应包含用户目标、宿主选定的焦点未知、最近问题、工作记忆切片、纠正、敏感边界和负担信号；一次输出下一波 3–5 题及目的，所有题均可跳过。
- Sensemaker 输出运行时校验的 memory patch 与一条 `ImmediateInsight`；洞察必须包含有效 `evidence_ids`、暂定程度和中性校准邀请，事实/解释/未知的详细状态保存在 WorkingMemory。
- 附件内容用明确的数据边界包裹，视为用户提供的数据而非指令；简历/MBTI 缺失不能改变核心流程资格。
- 每次短波结束先让用户确认/纠正，再将洞察用于三年路线；未经确认的内容仍可使用但必须标为 tentative，不得悄然升级为事实。
- Prompt 和模型版本可追溯；结构化失败、超时或 fallback 时不拼凑洞察，向用户说明暂时无法生成并保留回答。
- 对医疗、法律、财务、诊断和危机内容执行由 privacy-ai-safety dossier 定义的边界，不临场编造资源。

## Questions that could change the stance

- 双 Agent 是否需要分模型，取决于真实延迟、结构化通过率和成本；在证据前默认同一可靠模型、分 Prompt 职责更简单。
- 若用户测试认为每波确认打断自然感，可减少洞察数量或把纠正做成轻量批注，但不可取消可纠正性。

## Failure modes and proof signals

**失败模式**：从 MBTI 四字母演绎整个人；把简历空白解释为能力不足；洞察没有反例或未知；用户纠正后旧结论继续污染路线；追问机械重复；模型超时后产生半截或未校验结论；温暖语言变成情感占有。

**验证信号**：黄金案例中事实/推断/未知分离正确；每条洞察均可解析到来源；对同一用户的反例能降低或改写假设；纠正后的后续问题发生合理变化；无上传时质量仍可接受；测试者感到被理解而非被分类；安全边界案例稳定命中且不会捏造所在地热线。
