# 人生试运行：柔化的编辑型新粗野主义视觉与动效方向

- Kind: experience
- Status: shaped
- Product: 人生试运行

## Experience intent

人生试运行采用 **Soft Editorial Neo-Brutalism／柔化的编辑型新粗野主义**。画面像一本可以填写、折叠和批注的当代中文独立刊物：暖调纸张、墨黑结构线、克制的钴蓝标记，以及逐张出现的对话纸条。它要有触感和鲜明编辑判断，但不能像高饱和糖果组件展、儿童手工页、企业 dashboard 或套模板的 AI 产品。

这套方向服务一次 10–20 分钟、以阅读与回忆为主的移动访谈。新粗野主义的明确轮廓帮助用户快速判断层级与可点击性；“柔化”则通过有限色彩、适度密度、短阴影和大块呼吸区，避免每个元素都在争夺注意力。

核心张力：

- **直率但不粗暴**：2px 墨线和硬阴影表达确定的界面边界；洞察内容仍以暂定、可纠正的语言呈现。
- **年轻但不幼稚**：钴蓝、错位纸片和大号编号提供玩心；不用糖果色拼盘、吉祥物或贴纸轰炸。
- **编辑感但不疏离**：大号中文衬线体承载关键陈述；操作、说明和长文使用高可读中性无衬线体。
- **有触感但不妨碍任务**：按下、换页和纸条显露提供轻反馈；动画永远不决定业务状态，也不延迟作答。

## First-five-seconds composition

首屏必须让用户立即理解：回答几个短问题，会得到有依据且可纠正的理解，之后能看见三种可试玩的人生。画面不展示功能矩阵。

- **移动端**：顶部小型文字标志；中部大号两至三行中文主张；其下是一张洞察纸条样张；底部附近只有一个钴蓝主按钮与低权重说明。
- **桌面端**：使用不完全对称的 12 栏编辑网格。主张跨 6–7 栏，洞察纸条栈跨 4–5 栏，中间保留明显空白；不是左侧栏加右侧数据卡。
- **背景**：暖白纸面叠加细微方格。网格只提供尺度感，不承担进度或评分语义；正文密集区可降低网格对比或以实色纸片覆盖。

## Visual system

### Palette

全产品以纸、墨和一个主导钴蓝为基础。绿色只表示语义成功，不作为第二品牌色；错误使用偏砖红并配文字，不用颜色单独传达状态。

| Token | Seed | Role |
| --- | --- | --- |
| `--paper` | `#F5F0E6` | 页面主背景、暖调纸张 |
| `--paper-raised` | `#FFFDF7` | 问题卡、洞察纸条、弹层 |
| `--ink` | `#171717` | 正文、边框、硬阴影 |
| `--ink-muted` | `#5B5A55` | 次要说明；仍需满足对比度 |
| `--cobalt` | `#2457E6` | 主 CTA、选中态、当前进度、链接 |
| `--cobalt-soft` | `#DCE5FF` | 低强度选中底、引用标记 |
| `--success` | `#2D7D46` | 仅用于上传成功、保存成功等语义成功 |
| `--success-soft` | `#DDEEDF` | 成功背景，必须配图标或文字 |
| `--danger` | `#B83A2F` | 错误与危险动作，必须配说明 |
| `--grid` | `rgba(23,23,23,.075)` | 背景方格线 |

规则：

- 同一屏通常只出现纸、墨、钴蓝；成功或错误色仅在对应状态短暂出现。
- 三条路线不得用绿／黄／红暗示优劣。可用不同的钴蓝网纹、编号和构图区分，结构与按钮权重保持一致。
- 普通文本对比度至少 4.5:1，大文本与关键图形至少 3:1；任何“柔和”都不能靠不可读的暖灰实现。

### Line, radius and shadow

- 默认结构边框为 `2px solid var(--ink)`；分隔线可降为 1px，但交互边界保持 2px。
- 卡片和按钮使用 0–4px 圆角。需要变化时可采用单角 4px 或轻微切角，不使用大圆角和胶囊化容器。
- 默认硬阴影为 `3px 3px 0 var(--ink)`；大卡最多 `4px 4px 0 var(--ink)`。阴影不模糊、不发光、不叠多层。
- hover 可把阴影增至 4px；active 将元素平移 2px 并把阴影缩至 1–2px，形成真实按压感。状态变化不能造成周围布局位移。
- 非交互正文区不必全部加框。每屏优先保留一个主要带阴影表面，其余通过排版和细线组织，避免“组件样板墙”。

### Graph-paper background

方格使用两组 CSS linear-gradient 构成，建议 20–24px 基线、1px 低对比线。实现要求：

- 仅绘制静态 CSS 背景，不引入位图或动画噪声；
- 小屏和长阅读区降低 opacity，不能穿透输入框、弹层或洞察正文；
- 高对比模式下可关闭网格；打印或导出内容不依赖网格表达结构；
- 不把网格做成工程蓝图、坐标分析图或人格测量暗示。

## Typography

### Role split

- **中文编辑衬线**：只用于首页主张、即时理解 claim、路线核心陈述、章节开场和短引语。候选需选择有明确 Web 使用权、可按需子集化的中文宋／明体；实现前以真实中文字符集、字重和加载成本验证。未锁定字体时使用可审计的衬线 fallback stack，不虚构品牌字体。
- **中性无衬线**：用于按钮、表单、标签、导航、证据、状态、正文和长内容。优先系统中文无衬线与受控 Web fallback，保持加载可靠。
- **英文和数字**：跟随所在角色；编号可用紧凑 grotesk，不额外增加仅为装饰的字体家族。

### Scale and rhythm

- 手机 hero：40–52px，行高 1.02–1.12；桌面可到 72–96px，但不得挤压洞察样张和 CTA。
- 洞察 claim：手机 28–36px，行高 1.2–1.35；短句优先，最多 1–2 句。
- 正文：16–18px，行高 1.6–1.75；UI 标签不低于 14px。
- 中文不强行使用英文全大写逻辑；eyebrow 可用短中文、编号与较宽字距。
- 主要中文陈述避免伪斜体、超细字重和过度负字距。200% zoom 时内容自然换行，不裁切。

## Signature: printed dialogue slips

即时理解栈是人生试运行最重要的视觉签名。它不是聊天气泡，也不是一次性报告。**每个波次只生成一张完整纸条**，不同波次的纸条才会逐张累积成历史栈。

每张纸条包含一个 `ImmediateInsight`，内部按固定顺序呈现：

1. 波次编号与 `你告诉我的`：一至两条短观察及最多 2–3 个证据来源；
2. `我目前的理解`：使用编辑衬线承载唯一一条大号暂定解释；
3. `还不确定`：一行最可能改变当前理解或路线的未知，不显示置信度百分比；
4. `雷达变化 / 路线影响`：以两行轻量文本说明哪些维度因什么证据改变，以及它怎样影响未来探索；不得加入图表、总分或完成率；
5. 整张纸条共用一组 `准确`、`部分准确`、`不准确` 校准动作；
6. 独立的 `沿这里继续`、`换个方向`、`先看暂定路线` 与 `补一句`，不把导航意图误作事实确认。

出现方式：

- 一张纸条先作为整体加入普通文档流，内部三段以 60–100ms 间隔依次显露；整张纸条进入不超过 280ms。
- 下一波完成后才加入下一张纸条，可有 2–4px 横向错位；阅读顺序、DOM 顺序和焦点顺序完全一致，不旋转正文卡。
- 已出现纸条不因新纸条加入而被大幅推离视野；内部内容显露不抢焦点，校准控件在三段完整后一次出现。
- 当前波次纸条使用完整硬阴影；历史纸条可取消阴影并用细线分隔，避免堆栈越来越重。
- reduced motion 下纸条和内部三段立即出现或只做 100–140ms opacity；顺序仍由标签和文档结构表达。
- 禁止逐字打字机、闪烁光标、拟人化思考球、彩屑和庆祝轰炸。

## Journey applications

### Landing

主标题短促分行，样张展示一句具体、带“当前理解”标签的内容，证明产品不是长问卷。主 CTA 是唯一大面积钴蓝块；次级入口用有下划线的文本按钮。标志不使用外部素材或图形吉祥物。

### Questions and upload

- 持续对话中一次嵌入 1–3 张紧凑问题卡，通常 2–3 张；问题本身使用清晰无衬线或中等字号衬线，输入与帮助文本均用无衬线。
- 选项是近全宽方形卡：默认纸面、2px 边框；选中时使用钴蓝底或钴蓝内标记，并同时显示 check 与文本状态。
- 自由输入 composer 与卡片同等可见；卡片提交后折叠为可编辑的用户纸面气泡，不引入另一套圆润聊天皮肤。
- 主操作保持可见但不遮住软键盘；触控目标至少 44 × 44 CSS px。
- 上传是独立纸张模块，明确“可跳过”、格式、大小、用途、第三方模型处理与删除方式。每个文件显示文件名、大小、解析状态、重试和移除。
- 上传成功才使用绿色语义状态；等待、解析和选择不借用绿色。

### Three routes

三条路线像同一期刊物的三个平行封面：相同尺寸、相同边框、相同信息顺序和同权按钮。编号 `01 / 02 / 03` 大而明确，但不对应名次。

- 手机使用原生横向 overflow + scroll-snap，当前卡约占 86–90%，下一张露出边缘；同时提供上一张／下一张按钮、路线名称和 `1 / 3` 文本。
- 桌面在空间足够时三张并列，否则保留主卡与可访问预览；任何布局都不得默认突出一路。
- 差异通过封面排版、钴蓝图案和内容表达，不使用金银铜、皇冠、绿色赢家态或推荐角标。
- 选择路线后的文案明确“先验证，不是最终决定”；选择反馈只是按压与页面展开，不是胜利动画。

### Three-day trial and bounded chat

试验页面像可填写的三日工作纸：日期、最小动作、边界、记录与停止条件清楚分区。未完成不变红、不产生断签。对话继续使用纸条结构，但用户和系统通过标签、对齐和边框变化区分，而不是默认圆形聊天气泡。

危机与高风险信息使用稳定纸面、明确标题和可执行文字；不应用戏剧化颜色、震动或视觉惩罚。

## Motion grammar

Motion 只保留三类作用：顺序显露、状态反馈、布局连续性。

- 微交互：120–180ms；纸条与问题切换：180–280ms；页面级布局：最多 360ms。
- 缓动自然、无弹跳过冲；不持续漂浮、不自动摇晃、不做指针视差。
- 进入以 opacity + 8–12px 位移为上限；退出不应先清空用户草稿。
- layout transition 仅用于校准展开、纸条加入、路线详情展开等能帮助理解位置关系的场景。
- 同屏不设持续环境动画。loading 以静态步骤文字、进度条或低频纸条占位表达。
- `MotionConfig reducedMotion="user"` 作为基础，CSS 同时遵循 `prefers-reduced-motion`；用户手动设置可覆盖系统偏好。
- 动效库加载失败时，语义内容和操作以最终静态状态呈现。

## Responsive composition

- `< 640px`：单列，安全区内边距 16–20px；卡片近全宽；操作区避开 safe-area 与软键盘。
- `640–1023px`：可用 5:7 双区组织问题与上下文，上传说明与 dropzone 可并排。
- `≥ 1024px`：12 栏编辑网格，最大宽 1180–1280px；正文阅读列不超过约 68ch。
- 小高度横屏优先完整问题、输入与动作；缩减 hero、网格和装饰留白。
- 使用 `dvh`、safe-area inset 和容器查询；不能通过固定高度裁掉放大文字。

## Interaction and accessibility states

每个交互组件具有 default、hover（仅适用设备）、focus-visible、active、selected、disabled、loading、success、error 状态。

- focus-visible 使用至少 2px 钴蓝外环加纸色间隔，不能被 overflow 裁切；在钴蓝底上切换为墨线／纸色双环。
- disabled 保持可读，并就近说明原因；不能仅将 opacity 降到难以辨认。
- selected、success、error 均使用文字或图标冗余，颜色不是唯一信号。
- 异步洞察通过克制的 live region 通知，不逐字朗读流式 token，不抢焦点。
- 高对比、forced colors、键盘、屏幕阅读器、系统字号和 200% zoom 下保留完整任务。

## Errors, empty states, and recovery

- 网络中断：纸条和输入原位保留，显示“内容还在这里，重新连接后可继续”与重试动作。
- 洞察证据不足：明确“现在还不急着下结论”，提供继续一小轮或暂停；不用泛泛夸奖填空。
- 上传失败：文件行内显示原因、重试与移除，toast 仅作补充。
- 路线部分生成：成功卡保持可读，失败位置原位重试；未齐三条前不制造视觉冠军。
- 空态使用一段短说明、一个明确动作和必要结构线；不用大插画掩盖无内容。

## Anti-patterns

- 大面积高饱和多色卡、粗重 4px 以上边框、8px 以上硬阴影；
- 每个容器都有边框和阴影，造成组件展与长访谈疲劳；
- 大圆角、胶囊按钮、玻璃层、发光渐变、拟物黏土体积；
- 用装饰字体承载表单、证据、隐私和长文；
- 把洞察做成权威海报，视觉上压过“暂定”和纠正入口；
- 用绿色、位置、尺寸或动效暗示某条路线更好；
- 依赖外部插画、效果组件或持续动画才能形成品牌；
- 把方格背景变成进度、人格坐标或伪科学测量工具。

## Verification

1. **5 秒测试**：用户能说出“短问答—即时理解—三条可试玩路线”，而不是心理测评或通用聊天。
2. **视觉词汇**：目标词为“现代、成熟、有编辑感、清楚、可触摸”；“吵、儿童、廉价组件展、企业后台”任一显著出现即回调色彩、阴影或密度。
3. **10–20 分钟疲劳测试**：真机连续完成两波、校准和路线浏览；若用户注意边框、动画多于内容，减少带阴影表面与动态次数。
4. **360px 主路径**：软键盘打开时仍可完成所有题型、上传跳过、校准和继续。
5. **洞察签名**：claim、依据、不确定与校准无需长距离滚动即可建立关系；纸条顺序在无动画时仍清晰。
6. **三路平权**：测试者不会因颜色、位置、编号或动效将任一路线理解为推荐。
7. **无障碍矩阵**：键盘、读屏、200% zoom、forced colors、系统与手动 reduced motion 均可完成主流程。
8. **性能降级**：关闭背景、字体或 Motion 后内容层级、表单状态和恢复路径仍完整。
